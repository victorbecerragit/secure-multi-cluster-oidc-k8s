# DevSecOps Portfolio Rule

Always scaffold this repo as a professional portfolio project.

Requirements:
- Use Terraform for infra skeletons.
- Use Helm for deployable components.
- Use YAML for RBAC, policies, and workflows.
- Use Markdown for docs.
- Add Mermaid architecture diagrams.
- Prefer least privilege and short-lived credentials.
- Avoid fake complexity.
- Keep the repo clear, modular, and security-focused.
- Include validation examples such as `kubectl auth can-i`, `terraform validate`, and `helm template`.
